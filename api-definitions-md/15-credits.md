# Credits

### Get Credit Usage Report by Month
`GET {{instanceUrl}}/api/metrics/v1/usage/credits/reports/usage`
- Query: `startDate`, `endDate`

### Get Subscription Page/Contract Details
`GET {{instanceUrl}}/api/metrics/v1/usage/credits/reports/subscription`

### Get Credit Balance/Statements
`GET {{instanceUrl}}/api/metrics/v1/usage/credits/reports/balance`
